# 产品与安全边界

## 首版目标

`Aethor Studio V2` 首版只服务 `dummy-6dof` 六轴机械臂，是面向 Windows、兼顾展示效果与现场实用性的硬件调试平台。当前先完善前端和工程契约，再按阶段接入 C# 串口服务与 WebView2。

## 首版工作区

- 数字孪生：实体反馈模型、目标幽灵模型、六关节选择/拖动、模型树和显示工具窗。仅做正向运动学，不做末端拖拽逆解。
- 数据示波：关节反馈、目标与误差；静态阶段明确标记 `SHOWCASE`，实机阶段标记来源。
- 串口终端：协议帧查看、筛选、导出和离线格式校验；专家发送须会话级解锁。
- 设备与模型：设备、URDF、关节映射、限位、协议能力和资源来源。
- 动作编排：版本化 JSON、点位编辑、单点采集、校验和受控顺序执行。

## 已锁定操作规则

- 一次只选择并连接一台机器人；首版不虚构第二台机器人配置。
- 串口由用户手动选择并连接，COM4 只是当前已枚举端口，不得自动打开。
- 关节滑块和 3D 拖动只做本地目标预览；必须显式点击“下发整组关节角”。
- 真实动作只有在连接有效、反馈新鲜、设备已使能、目标合法、无在途命令且安全门通过时可用。
- 静态展示数据永远不能产生 `CONNECTED`、`ENABLED`、`COMMAND ACCEPTED` 或 `E-STOP SUCCEEDED`。
- 允许的 Dummy 结构化模式仅为 1–3；详情以 [Dummy ASCII v1](protocols/dummy-ascii-v1.md) 为准。
- 动作“暂停”不能伪装成固件队列暂停。首版必须采用诚实的逐点调度和确认语义。

## 软件停止语义

规划中的防御式停止链为：`!STOP → $0,0,0,0,0,0 → !DISABLE → #GETENABLE`。只有读回使能为 `0` 才能显示“已去使能”；任一步超时或失败都显示未确认并引导使用物理急停。

## 明确不包含

- 动力学、轨迹规划器、碰撞求解、末端拖拽、IK 和笛卡尔控制。
- MATLAB、Simscape、ROS、MoveIt、Zero-G、阻抗和连续示教录制。
- RGB、模式 4/5、电流/PID、标定、reboot 的结构化控制面板。
- 从现有 URDF 推断速度、effort 或安全回位姿态。
- 在后端缺席时模拟串口连接、设备回包、命令成功或急停成功。

未来扩展七自由度机械臂时，必须新增独立 Profile 和适配器能力声明；不得把 `dummy-6dof` 的限位、模式或安全假设复制过去。
