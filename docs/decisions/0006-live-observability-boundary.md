# ADR-0006：实时观测软件门与实机长测分离

- 状态：Accepted
- 日期：2026-08-09

> 2026-08-10 补充：本 ADR 的无 raw 结论仍适用于生产和任意串口文本。Development-only 的受限 Dummy 白名单由 [ADR-0009](0009-engineering-direct-debug-boundary.md) 单独取代终端解锁部分；它不是浏览器直串口，也不是任意 raw 端点。

## 背景

Phase 7 的缓冲、来源语义、刷新节流、导出和 UI 故障状态可以在不打开串口的条件下完整验证；真实采样稳定性、拔线恢复和持续资源曲线必须连接设备。Phase 5 Gate B 与 Phase 6B-H 尚未完成（6B-S 仅为无生产接线软件内核），但只读遥测不依赖运动包络，不能让运动门冻结独立的观测软件工作，也不能用合成压力测试冒充实机验收。

现行 `RobotGatewayV1.1` 刻意不提供 raw 串口端点。原阶段提示中的“专家发送”若直接实现，会绕过结构化命令、安全仲裁和审计边界。

## 决策

Phase 7 拆分为：

- 7A 软件门：有界遥测历史、来源/单位语义、图表节流与资源释放、真实协议帧视图、导出、session 隔离和故障状态。使用单元、组件、合成长测和三档浏览器测试完成。
- 7B 实机门：在新鲜监督授权下，使用只读网关完成持续采集、真实帧/网关证据核对、拔线或等价故障恢复和资源观测。未通过前 Phase 7 保持 `IN PROGRESS`。

`GatewaySessionCoordinator` 保持唯一 SignalR owner。页面不能订阅 hub；所有关节帧经 runtime store 的同一入口进入 `LiveSignalHistory`。每路容量为 4800 点并同时受 120 秒时间窗约束；18 路理论上限 86400 点。图表刷新独立限制为可见 10 Hz、隐藏 1 Hz。

终端专家解锁只开放本地命令文本编辑和格式校验。真实发送按钮固定禁用；未来 raw 能力必须另立版本化契约和安全 ADR。

## 影响

- 网关已配置但暂无帧时，示波与终端显示真实空缓冲，不回退 SHOWCASE。
- 同 session 重连或陈旧状态保留最后可信历史并明确标记；offline、unavailable 或 session identity 改变清空历史和专家解锁。
- 合成 10 分钟/40 Hz 测试只能证明容量和算法行为，不能证明 COM4、SignalR 或浏览器实际内存长期稳定。
- Phase 7A 可独立完成，但不能创建 Phase 7 完成提交。

## 验证与回退

自动化覆盖 120 秒时间淘汰、4800 点容量、24000 帧合成长测、乱序/重复/缺口、刷新节流、ECharts 单实例释放、协议帧去重、GETJPOS 显示切换与终端清空。若撤回 7A，可删除遥测历史 store/hook 并恢复静态页面，不影响 C# 串口所有权或结构化命令 API。
