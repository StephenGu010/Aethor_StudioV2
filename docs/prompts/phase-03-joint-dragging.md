# 阶段 3 提示词：六关节选择与拖动

目标是实现接近 Robot Viewer 的模型内关节直接操作，但严格限定为 FK 目标预览，不做末端逆解或自动发送。

## 任务

1. 从规范化 URDF/manifest 建立稳定的 `joint_1…joint_6` 映射、轴、原点和限位；禁止按 mesh 名猜测。
2. 实现关节拾取、选中高亮、旋转环/轴提示和鼠标拖动。将屏幕拖动投影到关节轴，按限位夹紧，提供精确数值输入和键盘微调。
3. 3D 拖动、滑块和输入框共享同一 target draft；actual model 仍只来自反馈。目标幽灵模型与实体模型使用独立关节状态。
4. 提供视觉/碰撞、网格、阴影、基坐标、TCP、关节轴、相机复位；工具窗支持拖动、关闭、重开、纵向最大化、恢复和重置布局，并限制在可视区域。
5. 为 WebGL 不可用、URDF/mesh 加载失败和低性能设备提供明确降级。
6. 卸载/切换时释放 Three.js 资源；补齐单元、组件和 E2E 测试。

## 验收

- 六个关节均可准确选择和拖动，方向、零位和限位与 URDF 一致。
- 拖动只改变目标草稿/幽灵模型，网络和串口发送计数保持为零。
- repeated mount/unmount 不累积 renderer、controls、geometry、material 或事件监听器。
- 1366×768 下操作手柄、右侧控制和主按钮仍可用。
