# 阶段 8 提示词：WebView2、发布与最终交接

目标是交付可安装的 Windows 桌面版。阶段拆为 8A 桌面软件门与 8B 正式发布门；8A 已验证但不等于最终交付。

## 8A 已完成

1. WinForms/WebView2 自定义标题栏、窗口动作、单实例和严格 `DesktopBridgeV1`。
2. 短期令牌、随机 loopback 网关、健康检查、Job Object、受控关闭和应用数据路径。
3. 自包含 win-x64 便携包、逐文件 SHA-256 清单、离线包 smoke、运行日志与 `docs/handoffs/phase-08.md`。
4. 浏览器模式不模拟原生成功；桌面生产包保持 `commandPolicy=disabled`，启动不打开串口。

## 8B 后续任务

1. 选择安装器并实现安装、升级、修复、卸载；默认保留用户动作、Profile 和日志，删除用户数据必须显式选择。
2. 建立正式代码签名/时间戳与干净提交发布流水线，禁止把 `development-dirty` 包作为候选。
3. 验证 Windows 100%/125%/150%/200% DPI、本地字体 fallback、三档分辨率和真实多显示器窗口恢复。
4. 实现受控网关崩溃恢复；串口或电机状态未知时不得自动重启并连接。
5. 完成 7B/8B 监督只读长测、拔线、关闭清理和句柄证据；任何运动仍需独立 Gate B。
6. 更新最终发布说明、验收矩阵和 `docs/handoffs/phase-08-final.md`，打开正式候选等待用户验收。

## 最终验收

- 干净 Windows 环境可安装、启动、升级和卸载；离线启动仍进入明确展示模式。
- 原生按钮只在 bridge 声明能力后启用；正常关闭无遗留网关进程，COM4 释放有独立监督证据。
- 五个工作区在三档分辨率、四档 DPI 下无关键裁切、重叠、字体回退错误或键盘焦点丢失。
- 版本、签名、许可证、模型来源和未验证限制准确；所有真实硬件结果有监督证据。
- 只有以上全部通过后，Phase 8 才能标记 `DONE` 并创建本地阶段提交。
