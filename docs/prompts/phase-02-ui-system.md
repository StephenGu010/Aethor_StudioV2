# 阶段 2 提示词：UI 字体、比例与信息架构

目标是把现有前端修正为展示级但可操作的工业控制台，不改变硬件能力边界。

## 任务

1. 审计数字孪生、数据示波、串口终端、设备与模型、动作编排五个工作区在 1366×768、1920×1080、2560×1440 的字号、行高、间距、栏宽、表格密度、滚动和焦点顺序，保存修复前证据。
2. 建立精简 token：石墨背景、低噪分隔、白色主操作、绿/黄/红语义色；字体限定本地 `Segoe UI Variable / Microsoft YaHei UI / Cascadia Mono`。
3. 调整标题栏、导航、状态带、3D/控制区和底部数据区比例。1366×768 使用紧凑密度与局部滚动；导航、关键状态、急停和主下发区保持可达。
4. 完成 loading/empty/error/offline/showcase/disabled/focus/hover 等状态；浏览器窗口按钮保持能力禁用。
5. 保持中文操作、英文工程状态/来源/单位；不引入在线字体或通用后台模板视觉。
6. 动作编排仅建立可发现的信息架构入口；编辑、导入、保存和执行保持禁用，并明确归属阶段 6。
7. 更新组件测试、Playwright/视觉基线和 handoff。

## 验收

- 三档视口无关键裁切、重叠、布局跳动和横向页面滚动。
- 最小正文、标签、数值字体在 Windows 缩放下清晰，等宽数值对齐稳定。
- 键盘焦点可见，禁用原因可发现，颜色不是唯一状态提示。
- 所有静态页面继续显示 `SHOWCASE DATA / SERIAL OFFLINE`。

完成后写 `docs/handoffs/phase-02.md`，列出视觉基线和仍需设计确认的项目。
