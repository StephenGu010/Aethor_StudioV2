# 验收矩阵

| 范围 | 自动化/检查 | 实机要求 | 通过标准 |
|---|---|---|---|
| 阶段 0 基线 | TS strict、Vitest、build、Playwright 四路由 | 禁止访问串口 | 三档视口无控制台错误；命令均可复现 |
| Profile/导入 | Schema、关节映射、限位、路径安全、缺失 mesh | 无 | 拒绝路径穿越、URL、重复关节、DOF/限位错误 |
| 协议 | formatter/parser、随机分片/粘包、255 字符边界、异常行、FIFO、超时、取消、跨语言 vectors | 先用 fake serial | 与指定固件提交一致；未知帧保留可诊断信息；排除命令不可构造 |
| 状态隔离 | feedback/target、showcase/session、命令状态机 | 无 | 展示数据不能产生在线、使能或成功状态 |
| UI | 组件测试、键盘焦点、视觉截图 | 无 | 1366×768、1920×1080、2560×1440 无关键裁切/重叠/跳动 |
| 3D | 六轴映射、限位、拾取/拖动、卸载/切换 | 无 | 实体与幽灵独立；拖动不发送；GPU 资源被释放 |
| 网关 | 单元、集成、fake serial、端口占用/拔出/重连 | 阶段 4 监督连接 COM4，只读 | 单一串口所有者；反馈过期/断线立即降级 |
| 硬件命令 | 许可门、命令 ID、超时、审计、停止链 | 阶段 5 起，物理急停在手边，先低风险姿态 | 目标合法才发送；失败不变成功；去使能须 `#GETENABLE=0` |
| 动作编排 | Schema、迁移、逐点 runner、取消/恢复 | 阶段 6 监督执行低速短动作 | 不以固定 sleep 判断完成；停止后不遗留待发队列 |
| 示波/终端 | 有界 buffer、刷新节流、过滤、CSV/文本导出 | 阶段 7 验证真实帧 | 来源和单位字段存在；120s 后内存仍有界 |
| 桌面发布 | DPI、窗口能力、进程回收、安装/升级/卸载 | 阶段 8 Windows 真机 | 浏览器不伪造原生能力；退出不留后台进程或串口句柄 |

## 实机安全门

任何实机阶段开始前必须记录：操作者、机械臂周围净空、物理急停可达、供电状态、当前姿态、串口标识和测试命令范围。未经用户现场确认，不得自动打开 COM4 或发送运动/使能命令。

每次验收保存命令、时间、环境、预期、实际结果和日志路径。失败项必须保留原始证据，不能只写“已修复”。
