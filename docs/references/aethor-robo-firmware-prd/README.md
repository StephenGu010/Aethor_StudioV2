# Aethor_robo 七自由度固件开发规范

文档版本：`0.3.0-draft`<br>
更新日期：`2026-08-12`<br>
适用对象：Aethor_robo 首组 7-DOF 机械臂、DM-S3519-1EC 电机、DM3520-1EC 驱动器、DM-MC-Board02 控制板

## 1. 文档用途

本目录是七自由度机械臂固件与 Aethor Studio V2 联调的实施依据。文档覆盖固件边界、CAN 电机协议、上位机串口协议、FreeRTOS 任务设计、关节坐标对齐、同步关节运动、测试验收和阶段交接。

当前只编写规范，不表示对应固件和上位机功能已经实现。

## 2. 已锁定的工程条件

- 开发环境：STM32CubeMX + Keil MDK-ARM。
- 主控板：DM-MC-Board02，MCU 为 STM32H723VGT6。
- 操作系统：FreeRTOS。
- 电机总线：FDCAN1 外设工作在 Classic CAN 模式，标准帧，8 字节数据上限；DM3520 默认 1 Mbps，项目实际位率必须从现有 CubeMX 工程和驱动器配置双向核对后冻结。
- 上位机链路：控制板 UART，波特率尚未从现有 CubeMX 工程核对；`921600 8N1` 只是协议候选值，不是当前实现事实。
- 执行机构：7 组 DM-S3519-1EC + DM3520-1EC。
- 电机接收 CAN ID：十进制 `1–7`。
- 电机反馈 Master ID：十进制 `11–17`，一一对应 J1–J7。
- 控制目标：关节角控制、关节反馈、数字孪生同步、同步到达和渐变速度。
- 支持模式：首版先冻结一种全组驱动模式完成只读与位置速度联调，再评估 MIT；同一次整组运动不得混用模式，驱动模式切换属于维护操作，不是日常运动命令。
- 不实现：运动学逆解、笛卡尔控制、动力学补偿、碰撞规划和轨迹路径规划。
- 首轮只联调一组 7-DOF 机械臂；第二组机械臂复用相同协议和固件架构。

## 4. 推荐实施顺序

1. 冻结 CAN ID、Master ID、关节方向和机械零位定义。
2. 单电机验证供应商帧、单位、反馈和故障码。
3. 从任意电机子集开始只读发现，验证 ID 映射、异常 ID/冲突诊断，再扩展到七电机完整性和总线负载。
4. 完成 `aethor-arm-ascii-v1`，让上位机只读同步数字孪生。
5. 完成每次上电的关节参考位对齐，再开放单关节低速运动。
6. 先完成位置速度模式整组运动，再完成 MIT 模式的 250 Hz 同步插补。
7. 完成超时、总线故障、停止、去使能和长时间运行测试。
8. 将同一套控制器固件和协议部署到 Aethor_robo 的第二个七轴关节组，并在上位机中增加双会话和组选择。

## 5. 开发前必须补齐的参数

以下数据不能从当前 URDF 或通用示例推断，必须由机械设计、电机调试和台架测试确认：

| 参数 | 要求 | 记录位置 |
|---|---|---|
| J1–J7 方向 `direction` | 只能为 `+1/-1`，保证模型正方向与实机一致 | 固件 `arm_config.c` 与上位机 Profile |
| 机械参考位 `q_ref_deg` | 七轴已知姿态，必须能人工重复摆放或由工装定位 | 联调记录 |
| 软限位 `q_min/q_max` | 以机械干涉、线束和装配约束为准 | 固件与 Profile |
| 最大速度和加速度 | 每轴分别验证，不使用驱动器理论极限直接运行整机 | 固件配置 |
| MIT `Kp/Kd/T_ff` | 从低增益、无负载开始台架标定 | 版本化参数表 |
| 驱动器 `PMAX/VMAX/TMAX` | 启动时读取寄存器并与部署配置比对 | 启动诊断日志 |
| UART 实际波特率 | 与 CubeMX 和上位机同时核对 | `board_config.h` 与网关配置 |
| 首组机械臂标识 | 推荐 `arm-01`，不要在物理归属未确认前猜测左右臂 | 固件身份配置 |
| CubeMX 工程基线 | `.ioc` 路径、MCU 型号、FDCAN nominal timing、UART 实例/DMA/波特率、FreeRTOS tick 和 heap | Phase 0 配置快照 |
| 驱动运行模式 | 七个驱动必须为同一模式；切换后会复位的实际行为需单电机确认 | Phase 1 参数快照 |
